# 晶能融合自動腳本（Angels Online）

自動在「裝扮 融合／晶能」視窗一直循環：

1. 點 **能量晶化**
2. 下面 3×4 格會有一格亮燈
3. 若亮的是 **最大HP／攻擊力／魔攻／精準** 其中之一 → 點 **我要晶能加倍** →
   **確認「確認視窗」有跳出來**（沒跳出來就再按一次加倍）→ 點確認視窗的 **確定(✓)**
   若不是 → 直接再點 **能量晶化**（跳過）

一直重複，直到你按停。

> ⚠️ 自動化可能違反遊戲條款、有停權風險，請自行斟酌，後果自負。本工具只模擬滑鼠點擊。

---

## 熱鍵

| 鍵 | 功能 |
|----|------|
| **F1** | 開始／停止 循環 |
| **F2** | 離開程式 |
| **F3** | 即時測試：印出 4 個目標格目前的亮度（用來確認/微調） |
| **F4** | 設定「確定(✓)」按鈕位置：先手動點一次加倍讓確認視窗跳出，滑鼠移到 ✓ 上按 F4 |

滑鼠甩到螢幕左上角 = 緊急中止；終端機 Ctrl+C 也能結束。

---

## 怎麼用

### 1. 裝 Python
到 <https://www.python.org/downloads/> 下載安裝，安裝時勾 **Add python.exe to PATH**，裝完關掉所有視窗重開。

### 2. 校正（雙擊 `校正.bat`）
把遊戲切到「裝扮 融合／晶能」視窗，且**下面 3×4 格目前沒有任何一格亮燈**。依提示用滑鼠指：
- 「能量晶化」按鈕
- 「我要晶能加倍」按鈕
- 4 個目標格：最大HP、攻擊力、魔攻、精準（指格子正中央）
- 最後按 Enter 記下這 4 格「沒亮」的基準亮度

> 建議先在遊戲勾好 **「跳過動畫」**，判斷才快又準。

### 3. 執行（雙擊 `執行.bat`）
先按 **F3** 測試：讓某個目標格亮燈時按 F3，看該格「目前」亮度有沒有明顯超過「門檻」。
- 分得開 → 按 **F1** 開始循環。
- 分不開（漏抓/誤判）→ 調 `config.json` 的 `detect.lit_margin`（**誤判調大、漏抓調小**）。

---

## 判斷原理

按能量晶化後，整排格子都會變亮，但**真正亮燈的那格會比其他格明顯亮一大截**。
所以用「相對亮度」：4 個目標格中最亮的一格，若比第二亮的高過 `detect.lit_rel_margin`，
就判定它亮燈（否則就是大家一起變亮、沒有特別亮的目標）。用 F3 可即時看數值。

## 常見問題

- **游標會動但遊戲沒反應** → 用**系統管理員身分**執行 `執行.bat`。
- **判斷不準** → 用 F3 看數值，調 `detect.lit_rel_margin`（**誤判調大、漏抓調小**）；或格子取樣範圍 `detect.sample_w/h`。
- **太快來不及出結果** → 調大 `timing.after_crystallize`（並在遊戲勾「跳過動畫」）。
