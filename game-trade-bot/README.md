# 遊戲交易自動精靈（Game Trade Bot）

自動把右邊「道具」背包裡的綠色球（S.EXP）一顆一顆放到左邊「交易」視窗，一次最多 7 個（可調）。

它會**自動偵測背包裡哪一格還有球**（用顏色判斷），然後：
點一下球 → 點一下交易空格 → 放上去，重複，直到放滿 7 個或沒球為止。

> ⚠️ 自動化外掛可能違反遊戲服務條款，有被停權的風險，請自行斟酌，後果自負。這支工具只做「點滑鼠」，不會去改遊戲記憶體或封包。

---

## 需要什麼

- Windows（Mac/Linux 理論上也能跑，但下面說明以 Windows 為主）
- 已安裝 **Python 3.9 以上**（安裝時記得勾「Add Python to PATH」）
- 遊戲畫面在「主螢幕」上，且**交易視窗 + 道具背包同時打開、不被擋住**

---

## 怎麼用（3 步驟）

### 1. 校正

雙擊 **`校正.bat`**（它會先自動安裝套件，再進入**分區校正選單**）。

**記點方式**：把滑鼠移到定位，**直接按 Enter 就記錄**，不用切回終端機。
（這用到 `keyboard` 套件；若按 Enter 沒反應，改用「系統管理員身分」執行，或程式會自動退回「回終端機按 Enter」的方式。）

**分區校正選單**（做錯只要重做那一區，不用全部重來，✅=已設過）：

```
 —— 背包 / 交易格 ——
  [1] 完整校正 背包+交易格（第一次必做／換螢幕解析度）
  [2] 快速對位 背包+交易格（沿用間距，只指兩個左上角）
 —— 交易點位（F7 收交易 / F8 提交易）——
  [3] 交易請求（接受鈕，F7 收交易；需有交易邀請視窗）
  [4] 前置點（F8 右鍵→左鍵）
  [5] 準備交易鈕
  [6] 確認鈕
  [7] 對方橘燈
  [8] 交易點位 全部（3~7 一次做完）
  [0] 完成，離開
```

- **第一次**：先做 **[1] 完整校正**（回答幾欄幾列，再用滑鼠+Enter 指角落）：
  - 右邊道具背包：**左上角第一格** → **第一列最右邊那格** → **第一欄最下面那格**
  - 左邊交易空格：同樣三個角落
  - > 只要指這幾個角落，中間每格程式自己算。背包最底那排「禮物盒」是承租格、不是球，只框綠球那幾列。
- 之後只是**換了視窗位置**：選 **[2] 快速對位**，只指兩個左上角就好。
- 要用 **F7／F8** 才需要 **[3]~[8]** 的交易點位（要交易視窗開著）；**只有 F7 收別人交易**才需要 [3] 接受鈕。
- 每做完一區會**立刻存檔**，選單可以一直待著、想重做哪區就選哪區，做完選 **[0]** 離開。

完成後會產生／更新 `config.json`。

### 2. 先空跑確認（不會真的點）

打開終端機（在資料夾裡按住 Shift + 右鍵 →「在這裡開啟 PowerShell」），輸入：

```
python trade_bot.py --dry-run
```

滑鼠會依序移到「要點的球」和「要放的格子」給你看，但**不會真的點擊**。
確認它有指對位置。想看偵測細節可以再跑：

```
python trade_bot.py --debug
```

會在資料夾裡存一張 `debug_view.png`：
綠圈=有抓到球、紅圈=判定沒球、藍框=交易格順序。對照一下有沒有抓對。

### 3. 正式執行（用 F1～F6 熱鍵控制）

雙擊 **`執行.bat`**（或 `python trade_bot.py`），程式會進入「熱鍵待命」，
接著切回遊戲、把交易視窗開好，用鍵盤控制：

| 熱鍵 | 作用 |
|------|------|
| **F1** | **搬運 綠球（7 顆）**；搬運中再按一次 = **停止** |
| **F2** | **搬運 綠球（8 顆）**；搬運中再按一次 = **停止** |
| **F3** | **搬運 粉紅道具（8 顆）**（另一種顏色辨識）；搬運中再按一次 = **停止** |
| **F4** | **連點右鍵**開／關（單鍵開關） |
| **F5** | **連續左鍵點兩個位置** 開／關：第一次按會請你設定兩個位置（滑鼠放好各按一次 Enter），之後按 F5 就不停地點；**Shift+F5** 重設位置 |
| **F6** | **在固定位置連點右鍵** 開／關：第一次按會請你設定位置（滑鼠放好按 Enter），之後按 F6 就在那個固定點一直點右鍵；**Shift+F6** 重設位置 |
| **F7** | **收別人交易（放綠球）** 開／關：偵測有人要求交易 → 接受 → 放滿 8 格**綠球** → 按準備交易 → 偵測對方橘燈亮 → 按確認完成。⚠️ 會真的把球送出去，請小心測試 |
| **F8** | **收別人交易（放粉紅道具）** 開／關：跟 F7 完全一樣，只是放的是 **F3 的粉紅道具**（另一種顏色辨識） |
| **F9** | **提起交易端（自己發起交易）** 開／關：**前置點**（在記住的位置按右鍵→延遲→固定偏移位置按左鍵，用來開啟交易）→ 檢查交易視窗有沒有開：有開 → 按準備交易 → 等對方橘燈亮 → 按確認；沒開 → 重做前置點。不放物。**角色會移動** → 按 **Shift+F9**、瞄準角色**點一下**就更新位置 |

> **F7／F8／F9 的交易點位在「校正」時一併設定**：跑 `校正.bat` 進分區選單，設定交易請求(接受鈕)、前置點、準備鈕、確認鈕、對方橘燈。F7/F8 收交易需要接受鈕（要在有交易邀請視窗時設）。

以上都是系統級熱鍵，就算滑鼠焦點在遊戲視窗上一樣按得到。
搬完（或球搬完）會自動停下、回到待命，隨時可以再按 F1／F2／F3 跑下一輪。
要結束程式：關掉視窗或在終端機按 Ctrl+C（滑鼠甩到左上角可緊急中止動作）。

> F1／F2／F3 的顆數可改程式頂端的 `F1_COUNT` / `F2_COUNT` / `F3_COUNT`。
> F1／F2 抓綠球（用 `config.json` 的 `detection`）；F3 抓粉紅道具（用程式頂端的 `F3_COLOR` 色相範圍）。
> **F4 連點右鍵速度**可在 `config.json` 的 `timing.rightclick_interval` 調整（單位秒，越小越快）。

> 想不靠熱鍵、倒數後直接跑一次，可用：`python trade_bot.py --now`

**搬運（F1）太慢？加速：**
- 雙擊的 **`執行.bat` 已預設極速**（`--turbo`）。
- 手動跑可加：`python trade_bot.py --turbo`（極速）或 `--fast`（較快、更穩，若極速有漏點就用這個）。
- 想永久調整，改 `config.json` 的 `timing`：`move_duration`（滑鼠移動）、
  `click_delay`（拿起球後等待）、`between_items`（每顆之間），數字越小越快。

## 停止 / 安全機制

- **緊急停止動作**：把滑鼠快速甩到**螢幕左上角**，正在跑的搬運／連點會立刻中止。
- **F4**：連點右鍵是開關，再按一次 F4 就停。
- **結束程式**：關掉視窗，或終端機按 **Ctrl + C**。
- 每一步之間有短暫延遲，避免點太快遊戲來不及反應。

> 若按 F1～F4 沒反應：有些電腦要用**系統管理員身分**執行才吃得到全域熱鍵。
> 對 `執行.bat` 按右鍵 →「以系統管理員身分執行」再試一次。

### 游標會動、但遊戲沒點到？

程式預設在 Windows 用 **SendInput**（底層滑鼠事件，較能被遊戲接受），啟動時會顯示
「點擊方式：Windows SendInput（遊戲相容）」。若仍沒點到，依序試：

1. **用系統管理員身分執行**（遊戲若是管理員權限開的，腳本也要）。
2. 把 `config.json` 的 `timing.click_hold` 調大（例如 `0.06`）——有些遊戲需要按住久一點才算數。
3. 確認遊戲是**視窗模式**、且點擊座標正確（可跑 `python trade_bot.py --debug` 對照）。

## 抓不準？調 `config.json`

> **會按到空格子？**（背包空格是青綠色的遊戲，如 Angels Online）
> 空格的青綠色會被誤判成球。跑一次 **`python fix_color.py`** 一鍵修正
> （把顏色範圍收窄成只抓 S.EXP 球的橄欖黃綠色），再跑 `--debug` 確認。

用記事本打開 `config.json` 微調（改完存檔再跑）：

| 項目 | 意思 | 調整方向 |
|------|------|----------|
| `detection.fill_ratio` | 一格要有多少比例是「綠色」才算有球 | 誤判成有球 → 調高（如 0.25）；有球卻沒抓到 → 調低（如 0.08） |
| `detection.hue_min/max` | 綠色的色相範圍 | 球顏色不同時微調，跑 `--debug` 觀察 |
| `detection.sample_size` | 每格取樣的方框大小（像素） | 格子小就調小，避免吃到隔壁格 |
| `timing.click_delay` | 點球後等多久才點交易格 | 遊戲卡就調大（如 0.6） |
| `timing.between_items` | 每搬完一個等多久 | 同上 |
| `quantity.confirm_with_enter` | 點道具後若會跳「數量」視窗設 `true`，會自動按 Enter | 你的球是飾品(數量1)通常不用，設 `false` |

## 運作原理（想了解的人再看）

1. 用 `mss` 擷取整個主螢幕畫面。
2. 依照 `config.json` 的格陣座標，逐格取中央一小塊，用 OpenCV 轉 HSV，
   算「綠球顏色」佔的比例，超過門檻就判定該格有球。
3. 找出背包有球的格子。
4. **第一輪快速放**：照順序把前 N 格各放一顆還沒拿過的球，並記住每格用了哪顆，中途不重拍（快）。
5. **第二輪補放**：重拍畫面找漏擺（空的）格子 → **先用第一輪指派給那格的原球補**
   （那顆沒放到、還在背包，不會誤拿已在架上的球）；那顆也補不上才拿第一輪以外的新球。
   （`place_retries` 次，預設 2）
