# 遊戲交易自動精靈（Game Trade Bot）

自動把右邊「道具」背包裡的綠色球（S.EXP）一顆一顆放到左邊「交易」視窗，一次最多 8 個。

它會**自動偵測背包裡哪一格還有球**（用顏色判斷），然後：
點一下球 → 點一下交易空格 → 放上去，重複，直到放滿 8 個或沒球為止。

> ⚠️ 自動化外掛可能違反遊戲服務條款，有被停權的風險，請自行斟酌，後果自負。這支工具只做「點滑鼠」，不會去改遊戲記憶體或封包。

---

## 需要什麼

- Windows（Mac/Linux 理論上也能跑，但下面說明以 Windows 為主）
- 已安裝 **Python 3.9 以上**（安裝時記得勾「Add Python to PATH」）
- 遊戲畫面在「主螢幕」上，且**交易視窗 + 道具背包同時打開、不被擋住**

---

## 怎麼用（3 步驟）

### 1. 校正（第一次一定要做）

雙擊 **`校正.bat`**（它會先自動安裝套件，再開始校正）。

校正時，程式會請你把滑鼠移到幾個「格子的正中央」，然後回終端機按 Enter：

- 右邊道具背包：**左上角第一格** → **第一列最右邊那格** → **第一欄最下面那格**
- 左邊交易空格：同樣三個角落
- 幾欄、幾列、一次搬幾個，照著問答輸入即可

> 只要指這幾個角落，中間每一格的位置程式會自己算出來。
> 背包最底下那排「禮物盒圖案」是承租空格、不是球，**框綠球那幾列就好**。

完成後會產生 `config.json`。之後位置沒變就不用再校正。

### 2. 先空跑確認（不會真的點）

打開終端機（在資料夾裡按住 Shift + 右鍵 →「在這裡開啟 PowerShell」），輸入：

```
python trade_bot.py --dry-run
```

滑鼠會依序移到「要點的球」和「要放的格子」給你看，但**不會真的點擊**。
確認它有指對位置。想看偵測細節可以再跑：

```
python trade_bot.py --debug
```

會在資料夾裡存一張 `debug_view.png`：
綠圈=有抓到球、紅圈=判定沒球、藍框=交易格順序。對照一下有沒有抓對。

### 3. 正式執行（用 F1 / F2 熱鍵控制）

雙擊 **`執行.bat`**（或 `python trade_bot.py`），程式會進入「熱鍵待命」，
接著切回遊戲、把交易視窗開好，用鍵盤控制：

| 熱鍵 | 作用 |
|------|------|
| **F1** | **立刻開始**搬運（不用倒數，按下去就開始） |
| **F2** | **立刻停止**目前的搬運；若當下沒在搬，再按一次 F2 就**離開程式** |

F1／F2 是系統級熱鍵，就算滑鼠焦點在遊戲視窗上，一樣按得到。
搬完 8 個（或球搬完）會自動停下、回到待命，隨時可以再按 F1 跑下一輪。

> 想不靠熱鍵、倒數後直接跑一次，可用：`python trade_bot.py --now`

---

## 停止 / 安全機制

- **F2**：立刻停止（每個步驟、每段等待都會檢查，按下去馬上停）。
- **緊急停止**：把滑鼠快速甩到**螢幕左上角**，程式會立刻中止。
- 終端機按 **Ctrl + C** 也能結束程式。
- 每一步之間有短暫延遲，避免點太快遊戲來不及反應。

> 若按 F1／F2 沒反應：有些電腦要用**系統管理員身分**執行才吃得到全域熱鍵。
> 對 `執行.bat` 按右鍵 →「以系統管理員身分執行」再試一次。

## 抓不準？調 `config.json`

用記事本打開 `config.json` 微調（改完存檔再跑）：

| 項目 | 意思 | 調整方向 |
|------|------|----------|
| `detection.fill_ratio` | 一格要有多少比例是「綠色」才算有球 | 誤判成有球 → 調高（如 0.25）；有球卻沒抓到 → 調低（如 0.08） |
| `detection.hue_min/max` | 綠色的色相範圍 | 球顏色不同時微調，跑 `--debug` 觀察 |
| `detection.sample_size` | 每格取樣的方框大小（像素） | 格子小就調小，避免吃到隔壁格 |
| `timing.click_delay` | 點球後等多久才點交易格 | 遊戲卡就調大（如 0.6） |
| `timing.between_items` | 每搬完一個等多久 | 同上 |
| `quantity.confirm_with_enter` | 點道具後若會跳「數量」視窗設 `true`，會自動按 Enter | 你的球是飾品(數量1)通常不用，設 `false` |

## 運作原理（想了解的人再看）

1. 用 `mss` 擷取整個主螢幕畫面。
2. 依照 `config.json` 的格陣座標，逐格取中央一小塊，用 OpenCV 轉 HSV，
   算「綠球顏色」佔的比例，超過門檻就判定該格有球。
3. 每搬一個之前**重新截圖**再找第一個有球的格子——因為球會越搬越少，
   這樣就能「自動偵測還有哪一格可以點」，不會點到已經空掉的格子。
4. 用 `pyautogui` 移動滑鼠並點擊：先點球、（可選）按 Enter 確認數量、再點交易格。
